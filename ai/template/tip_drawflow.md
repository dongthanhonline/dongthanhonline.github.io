Hãy vẽ quy trình / cây phân cấp (workflow tree) cho nội dung dưới đây theo đúng định dạng sau:
1. Đặt toàn bộ kết quả trong KHOẢNG CODE BLOCK (```text ... ```).
2. Định dạng Plain Text thuần túy, thụt lề bằng ký tự Tab (\t).
3. KHÔNG dùng đánh số thứ tự (không 1., 1.1, A, B...).
4. KHÔNG dùng định dạng Markdown (không dùng *, -, +, **, ###).
5. Node gốc nằm sát lề trái, mỗi cấp con lùi vào đúng 1 Tab (\t).
6. Nội dung ngắn gọn, súc tích, dễ copy/paste vào Notepad++.
